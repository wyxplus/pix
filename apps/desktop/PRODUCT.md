# Pix desktop

## Register

product

## Users

Developers working with the pi coding agent across local projects and conversations.

## Product Purpose

A Tauri desktop shell for pi, with persistent projects, conversations, agent status,
and settings. The sidebar lets users start work and switch contexts quickly.

## Brand Personality

Focused, understated, familiar. The requested reference for the complete interface is the Codex desktop app;
preserve Pix's name and existing actions.

## Anti-references

Avoid decorative cards, prominent branding, and heavy separators in navigation.
The sidebar should read as a compact list, with a clear project/conversation hierarchy.
Settings and resource pages use aligned rows, subtle dividers, and consistent controls.
Conversation content stays central, with a quiet composer and compact toolbars.

## Design Principles

- Make starting and resuming work easy to find.
- Keep project navigation and conversation status legible at narrow widths.
- Use consistent alignment and restrained hover and selection feedback.
- Keep the settings entry anchored below the scrollable navigation.
- Respect existing light/dark themes, custom skins, and font preferences.
- Adapt to the available viewport when resizing or zooming: narrow the rail before
  folding it, keep compact navigation reachable as a drawer, and restore saved
  desktop widths and manual collapse preferences when space returns.

## Accessibility & Inclusion

Preserve keyboard navigation, accessible button labels, visible focus states,
reduced-motion support, and Chinese/English localization.
